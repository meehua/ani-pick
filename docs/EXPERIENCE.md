# 经验与坑（迁移自 Morikusa 项目）

> 2026-11-18 从 Morikusa 的文档（`07-evolution` / `08-cache` / `06-security` /
> `02-database` / `03-http` / 前端两篇）提炼的可迁移工程教训。每条附踩坑原因；
> 与本项目无关的（gin 特有、S3 预签名等）已剔除。**接手改动前过一遍，别重踩。**

## 缓存

- **没有唯一失效点的缓存不许加**。每个缓存必须有明确的、可枚举的失效时机
  （写路径主动失效或短 TTL 兜底），否则数据陈旧没人能解释。本项目现状：
  overview 缓存在抓取/设置/条目动作后 `invalidateOverview()`，搜索 count/meta/meta-tags 用短 TTL 兜底。
- **失效用"世代号"优于逐 key 清理**：全局计数 +1，条目回填加载时的版本号。
  本项目规模用"清空 map / 置零缓存"等效实现，但语义要一样：失效后绝不能把旧数据重新钉住。
- **缓存容器契约**：loader 在锁外执行（不持锁打 DB）；loader 出错不写缓存；
  空结果也缓存（防穿透）；容量有上限（防 key 无界增长）。
  现状：`metaTags` 上限 64、`countCache` 上限 256、`sessCache` 上限 512 均按此实现。
- **读己之写**：将来若加只读副本，写后必须立即读的查询走主库，否则从库延迟
  会把旧数据钉进长缓存。

## 数据库

- **基线迁移冻结，结构变更只加增量文件**（`migrations/000N_xxx.sql`）。
  坑：改已应用的迁移文件不会让存量库重放，只会让全新建库与既有库悄悄分叉。
- **主键用 `bigint GENERATED BY DEFAULT AS IDENTITY`**，手写 DDL 漏自增只有全新建库能暴露。
- **闭集枚举用 CHECK 不用 pg enum**（加值要迁移）；jsonb/可空列"未配置"写 NULL 不写空串
  （空串会 22P02 报错）；软删过滤 SQL 要手动带条件。

## 安全

- **真实 IP 不默认信任任何头**：XFF 类头可伪造，曾导致限流被绕过。
  必须限制"可信反代网段"，只有 TCP 对端在网段内才读头（本项目
  `ANIPICK_TRUSTED_PROXY_CIDRS`，fail-closed：不配置网段 = 完全不信头）。
- **限流状态必须有界**：按伪造来源能撑爆内存来设计上限（本机 limiter 4096 清理）。
- **会话 Cookie 只用于读；写操作再校验来源**（本项目 requireAdmin 校验
  Sec-Fetch-Site/Origin，配合 SameSite=Lax）。

## HTTP / 架构

- **单节点够用就别预埋分布式**。Morikusa 的多节点机制（跨节点缓存失效、任务亲和）
  上线三周整体移除——纯白付的复杂度。本项目单二进制 + 进程内缓存就是终态。
- **"业务结论不是错误"**：查询成功但为空返回 200 + 空数据，不用错误通道表达业务状态。
- **重复第二次就上提通用层**；兼容代码自包含在旧接口文件并在文件头写删除清单；
  "暂缓/不做"的决定要写下来，防止反复重新评估。
- **内核语义一次做对，旁路要收口而非打补丁**：发现同类问题在不同入口都能触发时，
  重设计统一边界，而不是逐个入口加补丁。

## 前端

- **页面不直接裸 fetch**：统一走 `api/client.ts`；401 全局处理。
- **URL 即状态**：筛选/翻页进查询串，刷新/分享后状态不丢（BrowsePage 已实现）。
- **64 位 id 一律 string**：超过 2^53 后 JSON.parse 舍入。Bangumi 条目 id 远小于
  2^53，本项目安全；未来接入任何雪花 id 时必须改 string。
- **资源缓存契约**：带 hash 资产 `immutable` 一年、index.html `no-cache`；
  版本串前后端同源注入。本项目已按此实现（assets 不可变 + theme-boot/index.html no-cache）。

## 流程

- **修 bug 先写复现测试再修**；期望值来自独立事实（手算/规格），禁止用实现同款公式
  重算期望——同义反复的测试永远通过。
- **删导出符号前全仓验证零引用**（接口断言、反射注册 grep 不到），删后必跑 build。
- **每步验证**：`go build ./... && go test ./...`，前端 `npm run build`（含 tsc），
  改动收口跑 `scripts/smoke.sh`。
